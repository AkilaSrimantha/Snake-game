# 🐍 Snake Game - Expo + TypeScript

A colorful and modern Snake Game built using **React Native**, **Expo**, and **TypeScript**. Play the classic snake game with a smooth interface and responsive controls optimized for mobile.

---

## 🚀 Features

- 🎮 Classic snake gameplay
- 🌈 Colorful snake & food design
- 📱 Mobile-friendly (works with Expo Go)
- 🧠 Smooth animation and movement
- 🏆 Live score counter
- 🐍 Snake head customization
- 🔁 Replay and reset functionality
